# V0.4 idle backgrounds, scaling, and update decisions

Date: 2026-08-22

## Scale-safe idle layout

- The application shell already creates an inverse-sized logical viewport before applying CSS zoom. The old idle screen used `100vh` inside that shell, which counted the physical viewport a second time and produced overflow above 100%.
- The idle screen now takes `100%` of its dashboard grid cell, with both grid and child minimum sizes set to zero. The empty grid disables scrolling so animated content can never increase its scroll extent.
- At 200%, a tall one-column calendar uses two explicit toolbar rows. All navigation, current time, search, refresh, Day/Week, and close controls remain visible and independently hit-testable.

## Idle backgrounds

- Waves remain the default and first option for existing installations.
- The fish pond uses deterministic, code-native pixel SVG sprites for orange roughy, blue cod, snapper, sea perch, and gemfish. No remote image assets are required.
- The reactive background uses a fixed dot field and local pointer displacement. It does not retain pointer data.
- The topographic background reuses the shared map renderer with OpenTopoMap tiles and attribution. Its centre starts from the dedicated idle-map location, falls back to the weather location, then Melbourne.
- Slideshow folder selection uses the operating system folder picker. Only supported image extensions are enumerated, a maximum of 500 entries is returned, and individual images are limited to 50 MB. The exact no-folder guidance is shown on the idle screen.
- Background selection is available on the idle screen itself and is persisted with the rest of the settings.

## Update assistant

- GitHub Releases is the authoritative update channel. Draft releases are ignored; prereleases remain eligible so lettered releases can be distributed.
- Custom version comparison treats numeric components first, then letter suffixes. A suffix-free version is considered the final release and sorts after its lettered builds.
- Installer URLs must be HTTPS release downloads from `BananaAficionado/DailyDashboard`. GitHub's reported `sha256:` digest is checked when present.
- Windows “install now” launches the verified NSIS executable silently and exits the dashboard. “Install next reboot” writes a current-user `RunOnce` command, requiring no machine-wide service or administrator-only startup task.
- macOS can check and download a DMG, but automatic installation is deliberately not performed; the release page remains the handoff. The Windows workflow publishes tagged NSIS installers so future tagged versions become discoverable.
- “Ignore updates” disables automatic checks and installation. Changing the preference does not silently install an already downloaded file.

## Verification matrix

- 1280×400: 75%, 100%
- 1920×720: 100%, 150%, 200%

The responsive smoke test validates viewport and scale, pairwise non-overlap and hit-testing of calendar controls/current time, calendar sidebar access, empty-screen scroll dimensions, fish rendering, and slideshow folder guidance. Frontend unit/static tests and Rust updater version tests are also required.
