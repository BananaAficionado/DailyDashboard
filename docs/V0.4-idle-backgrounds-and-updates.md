# V0.4 idle backgrounds, scaling, and update decisions

Date: 2026-08-23

Current release: V0.4.5. It is newer than V0.4.4 so existing installations detect the compact clock layout refinements through the in-app updater.

## Scale-safe idle layout

- The application shell already creates an inverse-sized logical viewport before applying CSS zoom. The old idle screen used `100vh` inside that shell, which counted the physical viewport a second time and produced overflow above 100%.
- The idle screen now takes `100%` of its dashboard grid cell, with both grid and child minimum sizes set to zero. The empty grid disables scrolling so animated content can never increase its scroll extent.
- At 200%, a tall one-column calendar uses two explicit toolbar rows. All navigation, current time, search, refresh, Day/Week, and close controls remain visible and independently hit-testable.

## Idle backgrounds

- Waves remain the default and first option for existing installations.
- The fish pond uses deterministic, code-native pixel SVG sprites for orange roughy, blue cod, snapper, sea perch, and gemfish. No remote image assets are required. Each fish has its own steering state, pursues the cursor independently, circles after arriving, and eases back into autonomous wandering after the pointer leaves. Food takes priority over the cursor, attracts the nearest fish, and is removed as soon as a fish reaches it.
- The stars background computes local sidereal time from the chosen latitude, longitude, date, and time, then projects catalogue right ascension/declination coordinates into an altitude/azimuth sky dome. Hoverable constellation segments and star-centred targets reveal short educational descriptions; their invisible selection strokes are deliberately much wider than the visible lines.
- The topographic background reuses the shared map renderer with Esri World Hillshade elevation tiles, without the separate reference layer that contains roads and place names. Its centre starts from the dedicated idle-map location, falls back to the weather location, then Melbourne. A slow eased tour requests nearby named peaks, waterfalls, hiking routes, paths, tracks, streams, and rivers from Overpass, then centres on those coordinates without rendering their names. If feature discovery is unavailable, a local multi-waypoint terrain route is used instead.
- Slideshow folder selection uses the operating system folder picker. Only supported image extensions are enumerated, a maximum of 500 entries is returned, and individual images are limited to 50 MB. The exact no-folder guidance is shown on the idle screen.
- Background selection is available on the idle screen itself and is persisted with the rest of the settings.

## Update assistant

- GitHub Releases is the authoritative update channel. Draft releases are ignored; prereleases remain eligible so lettered releases can be distributed.
- Update checks and asset downloads use public GitHub Releases without authentication. See [current update behaviour](startup-updates.md).
- Custom version comparison treats numeric components first, then letter suffixes. A suffix-free version is considered the final release and sorts after its lettered builds.
- Installer URLs must be HTTPS release downloads from `BananaAficionado/DailyDashboard`. GitHub's reported `sha256:` digest is checked when present.
- Windows “install now” launches the verified NSIS executable silently and exits the dashboard. An NSIS post-install hook starts the newly installed, versioned executable after installation completes, avoiding a stale executable path. “Install next reboot” writes a current-user `RunOnce` command; the same hook relaunches the app after that deferred installation.
- macOS can check and download a DMG, but automatic installation is deliberately not performed; the release page remains the handoff. The Windows workflow publishes tagged NSIS installers so future tagged versions become discoverable.
- “Ignore updates” disables automatic checks and installation. Changing the preference does not silently install an already downloaded file.
- Settings locates the greatest release on the previous numeric version and reinstalls its platform-appropriate, digest-verified asset. For V0.4.4 this restores V0.4.3 while retaining the local settings file.

## V0.4.3 responsive clock

- `half` and `tall` one-column layouts render a minimalist analog face with hour/minute marks and a second hand synchronized every 100 ms.
- `wide` and `full` layouts render a condensed, straight-sided digital face; `full` adds today's connected calendar agenda on the right.
- The `half` layout places today's first three calendar items beside the analog face.
- The timezone selector is inside the widget, defaults to system time, saves immediately, and supports UTC plus common IANA zones.
- The clock has its own release feature flag and remains enabled by default.

## V0.4.4 clock interaction and presentation

- Agenda rows are buttons that open a compact, scrollable event-detail surface using the same calendar metadata as the main calendar widget.
- Analog and digital presentation is selectable inside the widget and persisted as `clockFaceMode`.
- Agenda placement is independent of the chosen face: it appears on the right for every layout except the one-column full-height form and scrolls when necessary.
- The timezone control uses an application-owned scrollable menu so it stays within the dashboard window on Windows.
- Rollback compares numeric version components, so V0.4.4 rolls back to V0.4.3.

## V0.4.5 compact clock layout and event transitions

- Digital typography uses the clock face's own container dimensions, preventing the readout or date from overflowing one-column and half-height layouts at any supported application scale.
- Half-height analog clocks omit numerals and use the full available face area instead of an artificial pixel cap.
- Event details replace the agenda inside its existing side pane. The grid smoothly reallocates space from the clock while the detail pane enters, then reverses the motion when it closes.
- Motion honours the operating system's reduced-motion preference.

## 2026-08-22 ambient refinement

- Fish now have species-specific pixel silhouettes, proportions, fins, stripes/mottling, and colours for orange roughy, blue cod, snapper, sea perch, and gemfish. Nine independent steering agents combine gentle wandering, boundary avoidance, separation, target pursuit, and clockwise/counter-clockwise cursor orbits.
- The former reactive sea is migrated to the location-aware Stars option for existing saved settings.
- The background chooser is transparent until its bottom hit area is hovered. Keyboard focus still reveals it, while pointer selection releases focus so it hides after the pointer leaves.
- The ambient topographic map starts at zoom 12 and follows eased 32-second feature-to-feature legs with short pauses at each destination. Direct pan or zoom pauses the automatic tour for 20 seconds before it resumes from the user’s current view. Visible provider attribution is suppressed on the ambient surface as requested.
- Selecting an album folder saves immediately, scans supported images up to three subfolder levels, and refreshes the slideshow without requiring a separate Settings save. The generic no-widget message is hidden when the no-folder slideshow guidance is displayed.
- Slideshow fit is persisted as either crop-to-fill or contain. Contain mode renders a second cover-sized copy behind the image with strong blur, dimming, saturation, scale, and slow drift so letterboxed areas remain visually connected to the photograph.
- The background menu remains fully visible for three seconds—the same duration as the left rail—after opening or selection, then fades unless hovered or keyboard-focused. Selected labels explicitly inherit the dark selected colour instead of the generic white idle-screen text rule.

- 1920×720: 100%, 150%, 200%
